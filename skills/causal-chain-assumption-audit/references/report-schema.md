# 報告結構與欄位契約

輸出檔名：`因果鏈與假設清單分析報告-<文件名>.md`，存於輸入文件同目錄。

## 章節

1. **分析文檔基本資訊**：文件名稱、來源（檔案／網址）、字數或頁數概估。
2. **段落層重要主張**：逐段列出的主張清單。
3. **骨幹層的選定結果**：選定的骨幹主張清單（使用者確認調整後的最終版本）。
4. **因果鏈清單**：表格欄位——編號｜Claim（主張）｜Grounds（作者寫出的理由）｜Warrant（橋樑原則）｜是否跳躍｜候選補充前提。
5. **假設清單（否定測試後）**：表格欄位——假設內容｜支撐哪一段推論｜移除後受影響的段落｜分類（常見／有爭議／高度不確定／事實依據不足〔可查證〕／論證原則需額外佐證）｜是否需要在前段明說。

只有第 4 節標記為「跳躍」且 Warrant 本身有疑義的項目，才會出現在第 5 節的假設清單裡。
